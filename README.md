# Zombie Chopper 3D — Code Portfolio

Selected C# gameplay and systems code from **Zombie Chopper 3D**, a Unity game project.

This is a code-only portfolio repository. It intentionally excludes scenes, art, audio, animations, packages, generated files, and third-party assets. It is not a complete runnable Unity project.

## Code areas

- Player, helicopter, runner, zombie, and boss controllers
- Weapons, projectiles, hazards, combat, and spawning
- Progression, ranks, rewards, shops, and in-app purchase systems
- UI, tutorials, audio, advertising, analytics, and game-state management

Built with Unity and C#.
